Module 2 — Minimal-git handout

Minimal git for homework — one page, six commands

The daily loop

From HW2 on, your homework IS a git repository: the commit history shows your process, and pushing is how you submit.

Every time you reach a stopping point, run these six commands:

  1. git status — what changed since my last commit?
  2. git diff — what exactly did I change, line by line?
  3. git add trapezoid.cpp — stage the file, by name: you are choosing what enters the record.
  4. git status — is what’s staged exactly what I meant?
  5. git commit -m "hw2: throw on non-positive n in trapezoid" — record it, with a message that says what and why.
  6. git push — hand it in. Pushed = submitted; committed alone is not submitted.

Your repo is graded on hygiene

Your repository contains ONLY what the assignment asks for: source files, tests, and the README.

Committed build artifacts — a.out, *.o, build/ — cost points.

.gitignore is how you enforce this on yourself: the starter repo ships one, and you are expected to maintain and extend it.

Why not git add .? Because it stages everything it finds, including files you never looked at — stage by name and read the second git status instead.

One-time setup

Do this once, before HW2 is assigned; it takes about 10 minutes.

  1. Install git and the GitHub CLI (gh):
OS Commands
macOS brew install git gh (install Homebrew from brew.sh first if you don’t have it)
Linux sudo apt install git gh (Ubuntu 23.10+; on older LTS follow cli.github.com/packages) · sudo dnf install git gh (Fedora) · sudo pacman -S git github-cli (Arch)
Windows install Git for Windows from git-scm.com, then winget install GitHub.cli

  1. Tell git who you are — run git config --global user.name "Your Name" and git config --global user.email "you@fsu.edu", using the SAME email as your GitHub account so your commits link to you.

  2. Run gh auth login — choose GitHub.com, HTTPS, and “Login with a web browser” — accept the defaults for the remaining prompts (they are what makes plain git push just work).

  3. Click the GitHub Classroom link posted with the homework — it creates your private repository from the starter.

  4. Run git clone <the URL Classroom shows you> in the folder where you keep coursework.

  5. cd into the cloned folder and run git status — “nothing to commit, working tree clean” means you are ready.

If any step fails, bring your laptop to office hours BEFORE HW2 is due — auth problems take minutes in person and days over email.
